BẮT ĐẦU

Chuẩn bị một lần.
Dùng trên máy của bạn.

CPX dùng compiler native để đóng gói C++. Cài hai công cụ sau trước khi mở app.

  1. Cài Zig

    Cài Zig và thêm thư mục chứa zig.exe vào PATH. Có thể cài qua Windows Package Manager:

    winget install zig.zig

  2. Cài MinGW-w64 qua MSYS2

    Cài MSYS2 tại C:\msys64, mở terminal MSYS2 và cài GCC:

    pacman -S mingw-w64-x86_64-gcc

    App tự tìm C:\msys64\mingw64\bin\g++.exe, bản UCRT64 hoặc g++ trong PATH.

  3. Mở CPX Encoder.exe

    Tải app, mở trên Windows và chọn file .cpp. Dùng tab một file hoặc nhiều file, sau đó copy hoặc lưu mã nộp.
